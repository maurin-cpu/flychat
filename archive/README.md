# archive/ — Abgeschlossenes, nur zum Nachschlagen

Hier liegt, was fertig ist und nicht mehr weiterentwickelt wird:
Einmal-Importe, abgeschlossene Recherchen, erledigte Debug-Skripte.
Nichts hier wird von der App oder von aktiven Skripten gelesen.

**Regel für Claude/KI-Werkzeuge:** Diesen Ordner bei Suchen, Analysen
und Refactorings IGNORIEREN. Nur hineinschauen, wenn der User
ausdrücklich nach einer Datei aus `archive/` fragt.

Beim Verschieben hierher gilt: Referenzen im aktiven Code müssen vorher
auf null stehen (grep), sonst gehört die Datei nicht hierher.
